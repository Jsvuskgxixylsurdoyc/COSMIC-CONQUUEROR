W, A, S, D: Walk / Move around
Spacebar: Jump
1:Change weapon
2: Change spell type (only works when the wand is equipped)
Left Mouse Click: Attack
Right Mouse Click: Defend (Note: the defend animation is just visual and doesnt help you, rely on dodging skills!)
left shift: sprint
escape: pause the game
